# Bert's Graveyard Supper

A tiny, slightly creepy, interactive browser experience in a single HTML file: cut Bert the spider loose from his thread, light up a spooky graveyard with your cursor, and feed him five things before he's full.

- Open `index.html` in a browser (sound on). No build step, no dependencies.
- Everything, including the music and sound effects, is drawn and synthesized in the browser.

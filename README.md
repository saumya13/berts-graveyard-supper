# Bert's Graveyard Supper

A tiny Halloween toy in a single HTML file: cut Bert the spider loose from his thread, light up a spooky graveyard with your cursor, and feed him five things before he's full.

- Open `index.html` in a browser (sound on). No build step, no dependencies.
- Cut the thread with the scythe, guide the light, sweep webs with the broom (`B`), cycle the sound with `M`.
- Everything, including the music and sound effects, is drawn and synthesized in the browser.
